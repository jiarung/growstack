## <a id="0729-inode"></a>2026-07-29 — bind mount 依 inode 脫鉤 ♻

**症狀** 容器看到的 `telegraf.conf` 與主機上的不是同一個檔，內容看起來卻一樣。

**證據**

| | inode | mtime | `mqtt_consumer` 數 |
|---|---|---|---|
| 主機檔案 | 44836170 | 2026-07-29 10:27 | 4 |
| 容器看到的 | 44836847 | 2026-07-21 09:40 | 3 |

**原因** Docker 以 **inode** 綁定單檔 mount。任何 write-new-then-rename 的編輯器都會讓它脫鉤，
**而 git 就是這種編輯器** —— `checkout` / `merge` / `pull` / `reset` 都會。
`docker restart` 沒有用，只有 `up -d --force-recreate` 會重新掛。

**處置** ♻ **會復發，不是修一次就好。** 08-31 又發生一次。
檢查與修法在 `MAINTENANCE.md` 的部署表與 `FLOWS.md` gap 3。
